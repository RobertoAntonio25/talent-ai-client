# 🚀 Talent AI - Frontend Client

Talent AI es un asistente de empleabilidad inteligente diseñado para revolucionar la búsqueda de trabajo. Este cliente web permite a los usuarios gestionar sus postulaciones mediante un panel Kanban interactivo, previsualizar CVs y cartas de presentación generadas por IA, y administrar su perfil laboral de manera eficiente.

## 🛠️ Stack Tecnológico (2026)

Este proyecto está construido con una arquitectura moderna enfocada en el rendimiento extremo y la escalabilidad:

- **Core:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vitejs.dev/) (Rendimiento optimizado y HMR ultrarrápido)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS)
- **Enrutamiento:** React Router DOM
